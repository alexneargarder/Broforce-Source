# Net

## Receiving
- `RPCController.Update` → `ProcessIncomingRPCS` → `ProcessRPCQueue`: an RPC runs once `TimeStamp <= Connect.GetInterpTime(sender)`, or at once if sent `immediate` (`addExecutionDelay` adds 0.5 s). While `Networking.PauseStream` (`Networking/`) is set this queue holds every RPC; the sender's own execution in `RouteRPCObject` still runs. `JoinScreen.StartGame` (`Menus/`) sets it with no online check, and an online `GameState.LoadLevel` (`GameFlow/`) sets it; `Connect.AllDeterminsiticObjectsHaveBeenRegistered` clears it from the `Start` of the `OnStart` component that `Registry.Awake` (`Core/`) adds. Held RPCs run once it clears, and `Execute` then drops those sent under the previous level's session ID: the `GameModeController.LoadNextScene` (`GameFlow/`) `AdminRPC` that `SwitchLevel` sends is immediate, so it runs ahead of queued RPCs not yet due and applies the new session ID before the pause starts.
- `NonStaticRPCObject.Execute` / `StaticRPCObject.Execute` return without a trace when the session ID is neither `Connect.SessionID` nor `SID.IgnoreID` (`GameModeController.SwitchLevel` and the world map's level start set a new one), when `Registry.GetObject` finds nothing, when an `Ack` reply is no longer awaited, or when `RPCSecurity.IsAllowed` (`Networking/`) refuses a method it found that lacks `[AllowedRPC]` (`Networking/`). Anything thrown while deserializing or invoking is swallowed by an empty `catch`.
- An RPC sent to an unregistered object carries `NID.NoID`, so `Execute` drops it on every client, the sender's own `TargetAll` execution included.
- `RPCSecurity.IsAllowed` requires `[AllowedRPC]` (inherited attributes count) on the method `type.GetMethod(name, Instance|Static|Public|NonPublic)` finds on the target's runtime type, or a static RPC's declaring type; when the name is overloaded, any overload carrying the attribute passes. A name `GetMethod` does not find logs `Method X.Y does not exist.`, the only drop on this path that logs: a private method declared on a base class (not found from a subclass), a target NID that resolves on the receiver to an object of another type (`Execute` passes `obj.GetType()`), or a receiver whose copy of the class lacks the method. `Destroy` on any `UnityEngine.Object` type and a short list of frequent calls pass without the attribute.

## Arguments
- `TypeSerializer.SerializeParameterList` serializes each non-null argument through the pre-generated `Serialize<T>` cache, a fixed list matched by the argument's exact runtime type. It holds `GameObject`, `Transform` and many game classes but not all (`Mook` (`Enemies/`), `Animal` (`Units/`) and `Map` (`Level/`) are missing), and never a class a mod declares. A type missing from it falls to `SerializeValueType`, which writes nothing for anything but `NID`, `Registry.ReplacementBlock` (and arrays of both), `NullWrapper`, `Vector2`/`Vector3`, `Quaternion`, `Color`, `GridPoint` (`Level/`), `ParentedPosition` and `BasePerk` (`Rogueforce/PerkSystem/`); every client's call then fails inside `Execute`'s swallowed exception, the sender's own included. Pass such an object as its `Registry.GetNID` instead.
- An object argument of a cached type travels as its NID and comes back as `null` on a client where that NID is not registered. An object of a cached type registered nowhere (plain `Object.Instantiate`, `AddComponent`) travels as `NID.NoID` and arrives as `null` on every client, the sender's own included: the method still runs, with `null` for that argument, unlike an RPC addressed to an unregistered object, which `Execute` drops.
- A static RPC's class is resolved on the receiver by `TypeSerializer.GetType`: `Type.GetType(name)`, else `Assembly.Load(<name up to the first '.'>)`. A static RPC in a mod assembly resolves only when its root namespace equals the assembly's name.
