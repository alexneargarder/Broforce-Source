# GameFlow

`GameState` is a plain object, not a scene object, carrying the next scene, seed, level number and session ID across a scene load. `GameModeController.LoadNextScene` applies the copy it is given (`GameState.Apply`, which makes that copy `GameState.Instance` and sets `Connect.SessionID` (`Net/`)) before loading the scene, so on a client each switch replaces the instance with the host's copy. `Apply` also copies `Map`'s (`Level/`) load offsets, super-checkpoint start and `persistPastLevelLoad` from the copy. `SwitchLevel`'s `FullRefresh` refreshes the others from `Map`, but `persistPastLevelLoad` reaches `GameState` only when the host handles a joining client (`Connect.RequestSyncedServerData`), so the flag `Map.PersistBlocks` raises when a campaign level fails is overwritten, normally with false, before `LoadSceneCore` calls `Map.CheckPersistBlocksPastLevelLoad`, which then destroys the persisted blocks, on every machine, offline too.

## Level end
- `GameModeController.LevelFinish(result)` sends `LevelFinishRPC(CurrentLevelNum, result)` to all unless `levelFinished` is already set locally. A receiver on a different level number ignores it; otherwise every `LevelFinishRPC` it receives sets `levelFinished` and `levelResult` and restarts a 2 s `winTimer`, later ones overwriting earlier ones.
- `GameModeController.Update`: when `winTimer` runs out, `TriggerManager.CheckAndTriggerLevelEndTriggers()` (`Triggers/`) fires an enabled, untriggered `LevelSuccess` trigger for `Success` or `LevelFail` trigger for `Fail` (other results match none) and parks the timer, leaving the rest to that trigger's actions. Otherwise `DetermineLevelOutcome` sets `nextScene` per game mode and starts `switchLevelDelay`. A campaign success (or any player on the helicopter) calls `LevelSelectionController.CompleteCurrentLevel()` (`CurrentLevelNum++`) and, unless `switchSilently`, shows `LevelOverScreen`, which holds `switchLevelDelay` at 100 s until it calls `GameModeController.SetSwitchDelay`.
- When `switchLevelDelay` runs out (and every player is ready, in modes that wait for it), `Update` calls `SwitchLevel`, which acts on the host only: it fills `GameState` (an incremented session ID, a new seed, the scene and level number), sends `LoadNextScene` to the others as an `AdminRPC` with `ignoreSessionID`, and loads locally. `RestartLevel` on a client asks the host to do it. Once the new session ID is applied, RPCs still carrying the old one are dropped.
