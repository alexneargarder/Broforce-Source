# Folder rules for decompile.py's placement step. Only the global-namespace types ilspycmd writes at the tree root are
# placed, each file moved to Source/<folder>/; namespaced folders stay where ilspycmd writes them.
# One rule per line: kind, key and folder, separated by spaces or tabs. Blank lines and lines starting with # are ignored.
#   class   matches the type's exact name.
#   base    matches the type or any ancestor in its base chain, the nearest ancestor's rule winning. External bases
#           match by simple name (ScriptableObject); the chain ends at its first external base.
#   prefix  matches the file name's leading word on a CamelCase boundary (the next character is uppercase, a digit,
#           an underscore or the end); the longest matching prefix wins.
# Precedence: class, then base, then prefix, else Unsorted/.
#
# Folders:
#   Enemies      hostile characters: mooks, aliens, hell creatures, Satan, bosses and their parts, the NPC AI framework
#                (PolymorphicAI, EnemyAI) with every enemy AI, and enemy-only helpers.
#   Projectiles  bullets, rockets, grenades and thrown or fired objects, a bro's or enemy's own included, and the
#                damaging blasts they spawn (flash bang, flame wall, ground wave).
#   Doodads      level objects that are not terrain tiles: doors, switches, crates, traps, mines, spikes, zip lines,
#                alarms, pickups, and the FallingBlock-based crate, hanging doodad, beehive and fire bin.
#   Blocks       terrain tiles: Block and its descendants (cages and barrels included), their pieces and decorations,
#                ground and terrain types.
#   Units        the unit framework (Unit, NetworkedUnit, TestVanDammeAnim), unit-wide helpers (pathfinding, damage
#                relays, parachutes) and neutral units: villagers, citizens, animals. Hostile units are in Enemies,
#                playable and bro-spawned ones in Bros, vehicles in Vehicles.
#   Bros         playable heroes: BroBase and every bro, hero types and unlocks, rescue cages' bro, each bro's own
#                helpers, allies and special abilities.
#   Vehicles     tanks, trucks, copters, blimps, bikes, diggers, mechs and their weapons and AI, the extraction
#                helicopter, the Harrier jet.
#   Players      a player's session: Player, HeroController, spawning, bot control, gestures, flex powers.
#   Core         the object model and game-wide foundations: BroforceObject, damage and death, damage policy,
#                startup, registry, time, instantiation, shared enums.
#   Net          networking: NetworkObject, RPCs, sync, serialization, IDs, connection layers, lobbies,
#                matchmaking, multiplayer chat, network debugging.
#   Level        the running level: the map and its controller, themes, generation, checkpoints, spawn points,
#                entry and exit portals, level-wide controllers.
#   Editor       the in-game level editor, level-chunk tools, Unity editor gizmos and developer launch tools.
#   WorldMap     the campaign world map: territories, missions, its helicopter, camera and effects.
#   GameFlow     game modes and the flow around levels: mode controllers, scene loading, pause, level end, score
#                and victory screens, intermissions, statistics.
#   Cutscenes    cutscenes, intros, endings and credits, and their props.
#   Menus        menu screens and their widgets: main menu, options, campaign browsers, save slots, hero select,
#                join screens, trophy room.
#   Hud          in-level overlays: player HUD, health and brotality bars, timers, money, on-screen text and alerts.
#   Triggers     level triggers, their actions and action infos, and the components that fire them.
#   Fx           transient visual effects: puffs, blood, gibs, debris, particles, decals, flashes, shakes,
#                the effects controller.
#   Graphics     rendering: sprites and sprite animation, textures, materials, image effects, cameras and the level
#                camera's follow, lighting.
#   Environment  the level's ambient world: weather, lightning, water, wind, foliage, wildlife, sky, backgrounds,
#                parallax, fluids.
#   Audio        sound effects, music and the announcer.
#   Input        controllers, keyboard and input readers.
#   Perks        Rogueforce perks, the perk shop and purchase switches, money and starting advantages.
#   Minigames    the burger minigame.
#   Platform     platform services: Steam, Playtomic, achievements, workshop, Alienware lighting, GIF and video
#                capture, build-variant switches.
#   Data         saved and file data: player progress and options, world map progress and save slots, campaign
#                and map files, file IO; ScriptableObject assets no subsystem claims.
#   Util         general helpers with no gameplay role: math, random, easing, extensions, singletons, logging,
#                small transform behaviours, test and debug scripts.
